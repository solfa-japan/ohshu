Core Features

OhShu が提供する4つの特別な体験

単なるゲームにとどまらない、深い教養と静寂な集中をもたらす洗練された機能群。

👁️

研ぎ澄まされる観察力

「主」と「王」、「門」と「問」、「道」と「通」など、一見すると見分けがつかない酷似した漢字が整然と並びます。細部を見抜く極上の脳トレパズルです。

📖

50篇の珠玉のみことば

正解するたびに、その漢字が織り込まれた聖書の名句と解説が静かに紐解かれます。知識としての漢字だけでなく、心に潤いをもたらす知の探求が待っています。

⚡

3段階の難易度設計

ゆったり遊べる Easy (4×4) から、本格的な Medium (6×6)、そして圧倒的な盤面密度の Hard (9×9) まで。子どもから大人まで夢中で楽しめます。

🏆

Game Center 世界ランキング

Apple Game Centerとシームレスに連携。ステージクリア速度と連続正解ボーナスでスコアを競い、世界の観察力ランキングの頂点を目指せます。

Scripture Library

心に灯る 50のみことばアーカイブ

アプリに収録されている50篇の聖句を自由に検索・鑑賞できます。日々の歩みのヒントや励ましとなる言葉を見つけてみてください。
